# CertIVCoach

CertIVCoach is an offline desktop coaching and assessment tool for Cert IV IT students. It helps you review concepts, test knowledge, and prepare for assessments.

## Features
- Practice quizzes with hints and glossary support
- Flashcards for spaced repetition
- Case study builder with DOCX export
- Student details tracking
- Data stored locally for privacy
- Designed for easy use and offline access

## Getting Started
1. Install Python 3.10+ and required packages:
   ```bash
   pip install -r requirements.txt
   pip install flake8 black
   ```
2. Run the app:
   ```bash
   python desktop.py
   ```
3. The app opens in a desktop window. You can also visit http://127.0.0.1:8799 in your browser.

## Linting & Formatting
- Check code style: `flake8 app/`
- Auto-format: `black app/`
